# Tài liệu dự án

| Thư mục | Nội dung | Ai cập nhật |
|---|---|---|
| `ba/` | Phân tích nghiệp vụ: brief, stakeholder, quy trình as-is/to-be, use case, sơ đồ, FR/NFR, user story, RTM (module `ba`) | playbook `kit-ba` |
| `architecture/` | Kiến trúc giải pháp arc42-lite, C4, phương án, sizing & chi phí (module `sa`) | playbook `kit-sa` |
| `plan/` | Roadmap, milestone, danh sách task, phụ thuộc | playbook `kit-plan` |
| `adr/` | Architecture Decision Records — mỗi quyết định kỹ thuật 1 file | playbook `kit-adr` |
| `qa/` | Test plan + test case theo từng task (`TASK-NNN.md`) | playbook `kit-testcases` |
| `security/` | Threat model, kết quả review bảo mật | playbook `kit-security` |
| `daily/` | Báo cáo hằng ngày `YYYY-MM/YYYY-MM-DD.md` + tổng kết tuần | `kit-daily` |

Bối cảnh cho agent (mục tiêu, kiến trúc, convention) nằm ở `.agent/context/`.
